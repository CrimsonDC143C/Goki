# Gymify Audio Assets Directory

This directory holds drop-in sound effect (SFX) and ambient music files (`.mp3`, `.wav`, `.m4a`).

Standard Sound Effect Keys:
- `level-up.mp3`: Triumphant fanfare when leveling up or clearing a 24-hour dungeon.
- `chest-open.mp3`: Reverberant unsealing chime when opening effort-gated chests.
- `micro-tick.mp3`: Tactile micro-reward click triggered per set log or progress tick.
- `critical-hit.mp3`: Heavy impact strike for PR breaks and battle crits.
- `anvil-strike.mp3`: Resonant metallic hammer strike for smithing and crafting.
- `stamina-full.mp3`: High-energy pulse chime when rest timer concludes.
- `timer-bell.mp3`: Sharp bell tone when dynamic countdown expires.
