# Gymify 2D Sprite Assets Directory

This directory holds drop-in 2D character portraits, combat sprites, item icons, and encounter artwork (`.png`, `.webp`, `.svg`).

Standard Sprite Categories:
- `heroes/`: Character class sprites (Juggernaut, Berserker, Vanguard, Warden, Outrider, Assassin).
- `enemies/`: Auto-battler combat sprites (Skeleton Warrior, Shadow Bat, Crypt Golem, Necromancer, Raid Bosses).
- `loot/`: Item and loot chest icons (Common Chest, Rare Chest, Epic Chest, PR Relic, Ore, Potions).
- `fx/`: Visual effect overlays (hit-slash, shield-barrier, critical-spark).
